# Fit Client (Fabric, Minecraft 1.21.11)

Original code. Not based on Anubis or 67Client code or assets. Uses the official Mojang mappings.

- Build: GitHub Actions builds on every push (Actions tab -> latest run -> Artifacts), or locally with `./gradlew build` (jar in `build/libs/`, use the one without `-sources`).
- Right Shift: open/close menu. F7: toggle Sus Chunks.
- Enable "Sus Chunks" (and "Sus HUD" for the on-screen list) in the Modules tab.
